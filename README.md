# Rikuto Mikado — Personal Portfolio

A sleek, responsive portfolio website showcasing my trajectory across **Physical Infrastructure & Electrical Engineering** and **Full-Stack Software Development**.

Designed with an editorial aesthetic, subtle fluid canvas animations, and seamless dark mode support.

---

## ✨ Features

- **Fluid Light Trails**: Lightweight, zero-dependency HTML5 Canvas background with undulating sine-wave ribbons, tapered shooting-star trails, and proximity constellation effects.
- **Day & Night Mode**: Instant toggle with smooth transitions, theme persistence (`localStorage`), and dynamic light/dark favicon synchronization.
- **Responsive Layout**: Tailored negative space, typography, and image scaling optimized for both mobile and high-resolution desktop displays.
- **Interactive Credentials**: Modal viewer for accredited certifications across full-stack engineering, Python automation, and culinary arts.
- **Editorial Typography**: Balanced serif titles combined with clean sans-serif UI elements.

---

## 🛠 Tech Stack

- **Framework**: [React](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Graphics**: HTML5 Canvas (Custom requestAnimationFrame engine)
- **Linting**: ESLint + typescript-eslint
